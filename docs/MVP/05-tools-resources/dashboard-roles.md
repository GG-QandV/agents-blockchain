# Member roles in the Alchemy Dashboard

The Alchemy Dashboard provides a default **Team** to manage your Alchemy apps. Here are the roles available in an Alchemy team, including role powers:

1. **Admin**

* Access an app's JWT keys
* Access Billing page
* Access Access Keys page
* Upgrade/Downgrade the team's plan
* Manage Gas Policies monthly limit
* Edit team name
* Make other users admin, remove from team

2. **Non-Admin**

* Create applications
* Create gas policies
* Create wallets policies
