Тесты: **191 passed, 0 failed**.

Найдено сверх списка и закрыто: обход resource-check (отсутствие ресурса при x402 или непустом
`resource_allowlist` → `DeniedDelta`; ресурс оффера обязан совпадать с ресурсом интента);
восстановление μ (догон, если `mu.log_head` — звено проверенной цепи; иначе отказ с кодом 2);
несовпадение owner-ключа vault и μ → отказ старта; таймаут чтения на сокете (молчащий клиент
больше не держит однопоточный цикл); отказ без оффера пишется в журнал (`DeniedNoOffer`,
код `0x15`) вместо молчаливого `Failed`.

Политика: журнал — источник истины (`DeltaApplied`, полный Δ + подпись владельца над
версией и хешами), `policy.toml` — кэш; защита от отката (подменённый/более новый файл →
демон не стартует); μ двигается за хвостом журнала после каждой записи (до этого второй
старт после первого платежа падал на `log_head mismatch`). Дифф перед подтверждением —
полный. Алерты — один раз на переход (`AlertAbout`), повторы в stderr.

Закрыто после сверки: 402-оффер передаётся в контексте исполнения (без состояния в
коннекторе), без оффера — `NoChallenge`, окно только из оффера (≤ часа), один оффер
оплачивается один раз (`OfferAlreadyUsed`).

Сверка с текстом задания по P0-5 (вариант A): окно берётся только из 402-оффера (дефолт 300 с
убран) и проверяется при подписи; reconcile-тесты «nonce не использован, окно идёт → резерв
сохранён» и «узлы расходятся → резерв сохранён + `AlertAbout 0x0A02`»; тест совместимости
старого журнала (байты тегов 1–12 неизменны, старый файл открывается, цепочка валидна).

Документация: `mu-daemon/README.md` (env, файлы, протоколы сокетов), `CHANGELOG-ksg.md`
(journal format 2, policy-endpoint, хеш, тест), `README.md` (счётчик тестов) — `454d0e1`.
