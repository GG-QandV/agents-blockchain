# mu-daemon — демон μ Gate

Слушает unix-сокет, гоняет интент через Ω → Δ → подтверждение владельца → WAL → коннектор,
возвращает вызывающему ответ с платёжным заголовком (x402) или кодом отказа.
Подтверждение владельца и применение политики — только здесь, в демоне.

Запуск: `cargo run -p mu-daemon --features softvault`.

## Переменные окружения

| Переменная | Обязательна | Значение |
|---|---|---|
| `MU_HOME` | нет (по умолчанию `/tmp/mu`) | каталог состояния: ключи, `agents.toml`, `policy.toml`, `mu.bin`, `mu.log`, сокеты |
| `MU_CONNECTOR` | нет | `x402` — реальные платежи; пусто/не задана — stub (`bank_stub`) |
| `MU_WALLET_ADDR` | **да для `x402`** | 20-байтный адрес кошелька плательщика; ключ из `keys/wallet.hex` обязан ему соответствовать |
| `MU_X402_NETWORK` | нет | `base` (по умолчанию) или `base-sepolia` |
| `MU_X402_RPC_1`, `MU_X402_RPC_2` | **да для `x402`** | два независимых RPC-узла для `authorizationState`; без обоих статус = `Unknown`, резерв не снимается |
| `MU_CHAIN_ID` | нет | chain id интентов (по умолчанию 8453) |
| `MU_MAX_CEILING_MINOR` | нет | потолок Ω в минорных единицах (по умолчанию 10 000 000 000) |

`MU_POLICY_SOCK` демон **не читает** — он сам открывает `<MU_HOME>/mu-policy.sock`.
Переменную выставляет оператор для Composer: `export MU_POLICY_SOCK=$MU_HOME/mu-policy.sock`.

## Файлы в `MU_HOME`

```
keys/mu.pub   ключ журнала (публичный)
keys/mu.hex   ключ журнала (закрытый, 0600)
keys/owner.hex  ключ владельца (закрытый, 0600) — подпись Δ и подтверждения
keys/wallet.hex ключ кошелька плательщика (закрытый, 0600)
agents.toml   id агентов и их публичные ключи
policy.toml   Δ: лимит дня, whitelist, порог подтверждения, allowlist ресурсов
mu.bin        текущий μ-объект
mu.log        журнал (hash chain)
run/            каталог сокетов: 0700, или 0710 когда задан MU_AGENT_UIDS
run/mu-daemon.sock   сокет интентов (0600, или 0660 для группы агентов)
run/mu-policy.sock   сокет предложений политики
```

## Сокет интентов (`mu-daemon.sock`)

Запрос: `len:u32 LE ‖ body` (wire v2, `body` несёт `resource`). Ответ — один байт:

| Код | Значение |
|---|---|
| `0x10` | отказ Ω (потолок) |
| `0x11` | отказ Δ (лимит/whitelist/ресурс) |
| `0x12` | владелец отказал |
| `0x13` | таймаут подтверждения |
| `0x20` | разрешено; для x402 далее `len:u16 LE ‖ X-PAYMENT` |
| `0x30` | платёж не прошёл |
| `0x40` | платёж уже в reconcile (ответ будет позже) |

## Сокет политики (`mu-policy.sock`) — Composer

Кадр тот же: `len:u32 LE ‖ proposal`. Порядок: размер → decode → `mu-policy::validate`
против Ω → сверка `base_delta_hash` с текущей Δ (TOCTOU) → дифф в stderr → вопрос владельцу
в stdin (`apply? [y/N]`). При любом ответе кроме явного `y`/`yes` Δ не меняется, ответ
`rejected: human_denied`. При применении пишется запись `DeltaChanged`, ответ `applied <hex>`.

## Старт и восстановление

На старте выполняется reconcile: `PendingAuth` → статус у коннектора; `Settled` → закрыт,
`Failed` → `Failed`; не определился после `valid_before + 60 s` → `Failed` (резерв снят);
узлы разошлись/недоступны → резерв сохранён, `Alert 0x0A02`. Legacy `Pending` без on-chain
ключа закрывается по `3600 + 60 s` с `Alert 0x0A01`. Несовпадение `log_head` с μ — выход
с кодом 2 (старая копия `mu.bin`).
